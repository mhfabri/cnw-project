# Estrelar

## Sobre o projeto

A **Estrelar** é uma landing page desenvolvida para uma loja de joias francesa fictícia, com o objetivo de apresentar a identidade da marca, seus produtos e seu conceito de forma elegante e visualmente atrativa.

O projeto foi desenvolvido utilizando HTML5 e CSS3, com foco na criação de uma interface moderna, organizada e responsiva, explorando elementos visuais que remetem ao universo de joias de luxo e à tradição da joalheria francesa.

Este projeto foi realizado como atividade acadêmica para a disciplina de Computação em Nuvem Para Web, do curso de Informática Para Internet da ETEC Maria Cristina Medeiros.

---

## Objetivo

O principal objetivo do projeto foi desenvolver uma **landing page para uma marca de joias**, colocando em prática conhecimentos de desenvolvimento web, estruturação de páginas e estilização com CSS.

A proposta também buscou trabalhar aspectos como:

- Criação de uma identidade visual;
- Organização e estruturação de conteúdo;
- Desenvolvimento de layouts utilizando HTML e CSS;
- Utilização de imagens e elementos visuais;
- Criação de uma experiência visual inspirada em marcas de luxo;
- Desenvolvimento de uma página com navegação entre diferentes seções.

---

## Sobre a Estrelar

A **Estrelar** foi criada como uma marca fictícia de joias de origem francesa.

A identidade da marca foi pensada para transmitir conceitos como:

> Elegância, tradição, sofisticação e exclusividade.

A estética do projeto utiliza elementos visuais inspirados no universo da alta joalheria, buscando representar uma marca que valoriza tanto o design de suas peças quanto sua história e legado.

## Como executar

Para visualizar o projeto localmente, basta clonar este repositório:

```bash
git clone https://github.com/mhfabri/cnw-project.git
```

Depois, entre na pasta do projeto:

```bash
cd cnw-project
```

Por fim, abra o arquivo:

```text
index.html
```

O projeto também pode ser executado diretamente utilizando uma extensão como **Live Server** no Visual Studio Code.
